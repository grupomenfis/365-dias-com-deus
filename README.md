# 365 Dias com Deus — V2

Versão funcional do site para GitHub Pages.

## Já pronto
- layout mobile aprovado
- calendário automático
- dia anterior / hoje / próximo dia
- seletor de outra data
- 27/11 reservado para Hebreus 10:24-25
- datas de Natal e fim de ano reservadas
- crédito ACF no rodapé
- conteúdo separado do código em `versiculos.js`

## Antes de publicar
Os textos integrais ACF e as referências restantes precisam passar pela conferência final. Os placeholders existem de propósito para impedir que uma versão incompleta seja publicada por engano.

## Publicação
1. Crie um repositório público no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e `versiculos.js`.
3. Settings > Pages > Deploy from a branch.
4. Escolha `main` e `/ (root)`.
5. Só gere o QR Code estático depois de revisar os 365 textos e testar o endereço final em celulares diferentes.
